# 3단계 - 영화 예매(데이터베이스)

## 기능 요구 사항

데이터베이스를 활용하여 영화 상영 정보와 예매 정보를 저장하고 조회할 수 있는 프로그램을 구현한다.

- 영화 상영 정보와 예매 정보는 데이터베이스에 저장한다.
- 프로그램을 다시 실행하더라도 저장된 영화 상영 정보와 예매 정보를 조회할 수 있어야 한다.
- 좌석 배치의 크기는 고정한다.
    - 상영관마다 좌석 수나 좌석 배치가 다른 경우는 고려하지 않는다.

# kotlin-movie

## 서비스 개요

- 한 영화관에서 쉽고 빠르게 영화를 예매할 수 있는 프로그램을 구현한다.

## 핵심 예매 규칙

- **상영 일정:** 하루 여러 차례 상영 가능하며, 상영 시간은 영화 길이와 운영 시간에 따라 결정된다. (동시 상영은 고려하지 않음)
- **중복 예매 방지:** 여러 영화를 한 번에 예매할 수 있으나, 시간이 겹치는 일정은 예매할 수 없다.
- **좌석 시스템:** 알파벳(행)과 숫자(열)로 구성된 좌석을 선택하며, 이미 예약된 좌석은 다시 선택할 수 없다.

## 가격 및 할인 정책

- **좌석 등급별 가격:** S석(18,000원), A석(15,000원), B석(12,000원)
- **추가 혜택 (중복 적용 가능):**
    1. **무비데이 할인:** 매월 10일, 20일, 30일 상영 시 **10% 할인** (우선 적용)
    2. **시간 할인:** 오전 11시 이전 또는 오후 8시 이후 시작 시 **2,000원 할인** (나중에 적용)
- **포인트:** 보유 포인트를 예매 금액에서 직접 차감하여 사용할 수 있다.
- **결제 수단 할인:** 포인트 적용 후 신용카드 **5%**, 현금 **2%** 추가 할인이 적용된다.

## 주요 구현 기능

- **영화/상영 관리:** 제목, 러닝타임, 상영 기간 및 일정 필터링/조회
- **예매/좌석 관리:** 좌석 배치 및 예약 상태 관리, 시간 겹침 검증, 예매 목록 추가
- **결제 계산:** 할인 정책(시간, 날짜, 결제수단) 및 포인트가 적용된 최종 금액 산출
- **포인트 관리:** 포인트 초기화, 사용 금액 검증 및 차감 로직
